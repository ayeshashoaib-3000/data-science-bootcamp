

# 🎓 Student Performance Analysis & Prediction

> **Can we predict a student's final score from their academic habits? 📊**

An end-to-end **Data Science & AI project** that explores student performance and uses **Machine Learning** to predict final scores.

## 🔍 What Does It Analyze?

📚 **Study Hours**
📅 **Attendance**
📝 **Assignments**
📈 **Previous Score**
🎯 **Final Score**

The project explores how these factors relate to academic performance through **EDA, visualization, and correlation analysis**.

## 🤖 Machine Learning

A **Linear Regression** model is trained to predict:

```text
Final_Score 🎯
```

using:

```text
Study_Hours + Attendance + Assignments + Previous_Score
```

### 📈 Evaluation

The model is evaluated using:

* **MAE**
* **RMSE**
* **R² Score**
